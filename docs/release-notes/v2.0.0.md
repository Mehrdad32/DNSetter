# DNSetter 2.0.0

نسخهٔ ۲ با Core مستقل و رابط کاربری جدید منتشر می‌شود:

- انتخاب صریح کارت شبکه و نمایش قابل‌کپی DNS فعلی.
- اعمال و بررسی IPv4 DNS فقط روی کارت انتخاب‌شده؛ تلاش برای بازگشت تنظیم قبلی در صورت شکست عملیات.
- Automatic DNS با رفتار روشن: دریافت خودکار DNS، بدون تغییر IP، Gateway یا IPv6.
- رابط WinForms قابل تغییر اندازه، میانبرهای صفحه‌کلید، پشتیبانی DPI و وضعیت عملیات داخل فرم.
- Ping غیرهم‌زمان با جدول نتایج، پیشرفت و لغو ادامهٔ تست هنگام بستن پنجره.
- اصلاح DNS دوم Google و جدایی DNS پیشنهادی از تنظیم فعلی.
- مستندات فارسی و انگلیسی و بسته‌های مستقل x64/x86 همراه SHA-256.

ZIP مناسب سیستم را استخراج و `DNSetter.exe` را اجرا کنید. نصب جداگانهٔ .NET لازم نیست؛ تغییر DNS به Administrator نیاز دارد. برای حفظ presetهای شخصی، `list.json` کنار برنامهٔ قبلی را نگه دارید.

**Automatic DNS تنظیم دستی پیش از یک تغییر موفق را بازیابی نمی‌کند.** برای بازگشت به DNS دستی، آدرس‌های قبلی را دوباره اعمال کنید. Ping تست ICMP است، نه DNS resolution؛ تست سایت نیز فقط پاسخ HTTPS را گزارش می‌کند.

---

Version 2 introduces a separate Core and a redesigned Windows interface:

- Explicit adapter selection and a copyable current DNS display.
- Verified IPv4 DNS writes to the selected adapter, with rollback attempts on failure.
- Clear Automatic DNS behavior, without changing IP addresses, gateways or IPv6.
- A resizable native UI with keyboard shortcuts, DPI support and inline operation status.
- Asynchronous ping tests with a results table, progress and cancellation.
- Corrected Google secondary DNS and separate pending/current DNS displays.
- Persian/English documentation and self-contained x64/x86 packages with SHA-256 checksums.

Extract the appropriate ZIP and run `DNSetter.exe`. No separate .NET installation is needed. DNS changes require Administrator access. Preserve your existing `list.json` when upgrading.

**Automatic DNS selects automatic DNS; it does not restore a previous manual configuration after a successful change.** Ping measures ICMP responses, not DNS resolution, and site reachability reports HTTPS status only.

Validation: 17 Core regression scenarios, a native Windows UI smoke check with simulated networking, and Windows x64/x86 publishing. Real Windows adapter behavior and the redesigned UI were also tested by the maintainer before release.
